# جامِع الجواهر — ديمو لعبة ثري دي ويب

لعبة ثلاثية الأبعاد بسيطة تعمل في المتصفح مباشرة باستخدام [Three.js](https://threejs.org)، بدون أي خطوة build أو تثبيت حِزم.

## اللعب
- **الهدف:** اجمع كل الجواهر قبل انتهاء المؤقّت (٦٠ ثانية).
- **التحكّم:**
  - الحركة: `W A S D` أو الأسهم.
  - القفز: `مسافة` (Space).
  - على الموبايل: أزرار اللمس تظهر تلقائيًا.

## المميّزات
- مشهد ثري دي مع إضاءة وظلال (shadow mapping).
- كاميرا تتبع اللاعب بمنظور خلفي مرتفع.
- فيزياء قفز وجاذبية بسيطة + منصّات يمكن الوقوف عليها.
- جواهر متوهّجة تدور وتعوم، ومؤقّت ونتيجة، وشاشتا بداية ونهاية.
- واجهة عربية RTL بنفس ألوان مشروع Rovi (بمبي/موف).

## التشغيل
الملف ذاتي الاكتفاء. شغّل خادمًا محليًا بسيطًا ثم افتح المتصفح:

```bash
cd game
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

> يحتاج اتصال إنترنت لتحميل Three.js من CDN. للعمل دون إنترنت، نزّل
> `three.module.js` محليًا وحدّث مسار الـ importmap داخل `index.html`.

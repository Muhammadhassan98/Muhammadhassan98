# منشئ السير الذاتية — CV Builder

موقع لإنشاء سيرة ذاتية احترافية مباشرة من المتصفح، مع **معاينة حية**،
**تصدير PDF**، **قوالب متعددة**، **حفظ تلقائي**، ودعم **العربية/الإنجليزية** مع RTL.
مبني بـ **React + Vite** بدون أي خادم — كل شيء يعمل في المتصفح.

## المميزات

- ✍️ **نموذج إدخال + معاينة حية:** كل ما تكتبه يظهر فوراً في السيرة الذاتية.
- 🖨️ **تصدير PDF:** زر "تنزيل PDF" يفتح نافذة الطباعة بمقاس A4 — اختر
  "حفظ كـ PDF" للحصول على ملف بجودة عالية يدعم العربية والخطوط بشكل سليم.
- 🎨 **٣ قوالب:** كلاسيكي، عصري (بعمودين)، بسيط — مع ٦ ألوان تمييز.
- 💾 **حفظ تلقائي:** بياناتك تُحفظ في المتصفح (localStorage) وتُسترجع عند العودة.
- 🌐 **عربي/إنجليزي:** تبديل فوري للغة الواجهة واتجاه الصفحة (RTL/LTR).
- 📑 **أقسام كاملة:** البيانات الشخصية، النبذة، الخبرات، التعليم، المهارات،
  اللغات، والروابط — كلها قابلة للإضافة والحذف.

## التشغيل

```bash
cd cv-builder
npm install
npm run dev        # http://localhost:5173
```

## البناء للنشر

```bash
npm run build      # ينتج مجلد dist/ جاهز للاستضافة على أي خدمة ثابتة
npm run preview    # معاينة نسخة الإنتاج محلياً
```

المشروع يستخدم `base: './'` لذا يعمل مباشرة على أي مضيف ثابت
(GitHub Pages، Netlify، Vercel، Cloudflare Pages…).

```

│       ├── Preview.jsx       # صفحة المعاينة A4

```

## كيفية تصدير PDF

اضغط **تنزيل PDF** → في نافذة الطباعة اختر الوجهة **"حفظ كـ PDF"** وتأكد أن
الهوامش **بلا (None)** و"رسومات الخلفية" مفعّلة للحصول على الألوان كاملة.
